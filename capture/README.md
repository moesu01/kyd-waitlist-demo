# Capture Reference Assets

This directory is meant to hold reference screenshots from the original KYD waitlist flow.

## Expected Structure

```
capture/
├── screenshots/
│   ├── desktop/
│   │   ├── 01-event-page.png
│   │   ├── 02-get-in-line.png
│   │   ├── 03-payment.png
│   │   ├── 04-processing.png
│   │   ├── 05-confirmation.png
│   │   ├── 06-on-list.png
│   │   └── 07-leave-waitlist.png
│   └── mobile/
│       ├── 02-get-in-line.png
│       └── 06-on-list.png
└── README.md
```

## Adding Screenshots

Place reference screenshots in the appropriate `desktop/` or `mobile/` subdirectory using the naming convention `XX-step-name.png` where XX is the step number.
