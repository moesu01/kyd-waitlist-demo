# KYD waitlist demo flow

The interactive demo follows the captured journey in [capture/docs/flow.md](../capture/docs/flow.md). Screenshot and HTML paths for steps 01–07 are listed in the [README](../README.md).

1. Event landing — JOIN WAITLIST on General Admission.
2. Get in line modal at quantity 0 (JOIN WAITLIST disabled).
3. Quantity 1 enables the lime JOIN WAITLIST button.
4. Payment page on the saved card. Join waitlist stays disabled.
5. Use a different card reveals the filled sandbox card and enables Join waitlist.
6. White confirmation screen. Got it continues.
7. YOU ARE ON THE LIST. LEAVE returns to the event landing.

There is no leave-confirmation modal and no real payment request.
